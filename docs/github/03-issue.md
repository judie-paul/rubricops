# Build the evaluator, reviewer and admin workspace

Provide a usable responsive interface for the complete review workflow.

Acceptance:

- Evaluators can claim, score, submit and release tasks without seeing peer scores.
- Reviewers can inspect paired scores and confirm, overturn or escalate.
- Admins can adjudicate, publish rubrics and import validated task batches.
- Dashboard and JSON export show real database-derived metrics and undefined cases.
- Desktop/mobile browser checks cover main workflows and API role restrictions.
