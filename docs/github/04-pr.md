# build: add reproducible local setup validation and measured documentation

Adds one-command database initialization, a persistent Docker Compose application,
CI quality/browser/container jobs, isolated database test tooling, measured seed
results, and deployment instructions. The README explains the pipeline, metric
semantics and the boundary between local verification and hosted configuration.

Validation: `make check`, PostgreSQL integration tests, production build, four
Chromium scenarios, and clean Docker build pass locally. Fresh seed: 32 tasks,
48 evaluations and 24 paired tasks; accuracy kappa 0.529412, one overturn in four
completed audits. These are synthetic fixture measurements, not human benchmarks.
Remote CI and hosted deployment must be verified separately after publication.
